# E-Commerce Sales Performance Analysis

## 📌 Project Overview

This project analyzes e-commerce sales data to understand revenue performance, customer purchasing behavior, product performance, and sales trends.

The project combines **MySQL and Python** to perform SQL-based data analysis and visualize the results using Pandas, Matplotlib, and Seaborn.

The analysis answers business-oriented questions related to revenue, transactions, product categories, customers, regions, and time-based sales performance.

## 🎯 Project Objectives

- Calculate total revenue generated by the business.
- Analyze the total number of transactions.
- Calculate the total quantity of products sold.
- Find the average transaction value.
- Identify the region with the highest number of customers.
- Identify top customers by total spending.
- Find the top products by revenue.
- Compare average transaction value across regions.
- Analyze revenue and quantity sold by product category.
- Calculate unique customers purchasing each category.
- Identify the number of unique products purchased by each customer.
- Analyze total spending and average transaction value per customer.
- Find the top products by revenue within each category.
- Identify the most popular product category in each region.
- Analyze the highest-revenue region for each product category.
- Calculate the percentage contribution of each category to total revenue.
- Study monthly, quarterly, and yearly revenue trends.
- Identify the months and quarters with the highest sales.
- Analyze sales by day of the week.
- Study customer purchase frequency and repeat purchases.
- Identify the highest-value customers.
- Explore the relationship between product price, sales quantity, and revenue.

## ▶️ How to Run the Project

1. Clone this repository:

   ```bash
   git clone <your-repository-link>
   ```

2. Make sure MySQL is installed and running.
3. Create or select the required database.
4. Import the required CSV files into the relevant database tables.
5. Update the MySQL connection details in the notebook:

   ```python
   db = mysql.connector.connect(
       host="localhost",
       username="root",
       password="your_password",
       database="your_database"
   )
   ```

6. Install the required Python libraries:

   ```bash
   pip install pandas matplotlib seaborn mysql-connector-python jupyter
   ```

7. Open `ecommerce.ipynb` in Jupyter Notebook or JupyterLab.
8. Run the notebook cells in order.
